MCA203P-AS05 — Solved Java Lab Sheet
====================================

Contains all 20 programs from Lab Sheet-05 as separate .java files.

Verification:
- All 20 Java files compiled successfully with javac.
- All 20 programs ran successfully in isolated test folders.

How to run a program:
1. Install a JDK (Java 8 or newer).
2. Open a terminal/Command Prompt in this folder.
3. Compile ONE selected file, for example:
   javac StudentMain.java
4. Run its matching public class:
   java StudentMain

Important:
Each question is a standalone program and several questions intentionally use
the same domain class names (such as Medicine, Patient, Employee, or Shape).
Therefore, compile/run one .java file at a time rather than compiling every
file together in one javac command.

For Q7, the public class/file is PatientMain_Q7.java to avoid colliding with
Q4's PatientMain.java when all source files are kept directly in one folder.
The required Patient class and validation behavior are retained.
